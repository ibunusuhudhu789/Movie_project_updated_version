# 🎬 My Top 10 Movies

A dynamic movie collection web application built using **Flask**, **SQLAlchemy**, **Flask-WTF**, and the **OMDb API**.  
This project allows users to search for movies online, add them to a personal collection, update ratings/reviews, and manage their favorite movies efficiently.

---

## 🚀 Features

- 🔍 Search movies using the OMDb API
- ➕ Add movies directly from search results
- ⭐ Update movie ratings and reviews
- 🗑️ Delete movies from the collection
- 💾 Store movie data using SQLite database
- 🎨 Clean and responsive UI using Flask-Bootstrap
- 🖼️ Display movie posters dynamically

---

## 🛠️ Technologies Used

- Python
- Flask
- Flask-Bootstrap
- Flask-WTF
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- OMDb API
